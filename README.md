<h1>📦 Database Setup</h1>
<ol>
  <li>Install a local server tool such as <strong>XAMPP</strong> or <strong>WAMP</strong>.</li>
  <li>Download the database file located at: <code>source/kasse.sql</code>.</li>
  <li>Import the database into your local server (e.g., using phpMyAdmin).</li>
  <li><strong>(Optional)</strong> If you want to rename the database or change the connection port, you can update the <code>host</code> variable in <code>com.utils.DatabaseConnection</code>.</li>
</ol>

<h1>⚙️ Requirements</h1>
<ul>
  <li>Java <strong>17 or higher</strong> installed.</li>
  <li>Maven <strong>3.8.1 or higher</strong> installed.</li>
</ul>
